# 乘用车新能源渗透率时序数据分析

项目简介：
本项目围绕乘用车燃油、新能源汽车月度销量时序数据开展分析。完成数据源获取、数据爬取、清洗结构化、统计指标计算，分析2025‑2026年月度燃油车与新能源车销量、新能源渗透率变化情况。

## 技术栈：
Python，Pandas，爬虫，CSV数据处理，时序统计分析

## 主要工作内容：
1. 数据采集：获取月度汽车销售原始数据，读取多份csv源文件，包含2025‑2026燃油、新能源汽车月度销量；
2. 数据清洗与结构化：处理空值、浮点精度问题，统一月份时间格式，完成多表对齐合并；，
3. 指标计算：计算总销量、新能源渗透率、同比增速、差值等统计指标，输出描述性统计结果；
4. 数据分析：分析新能源车、燃油车销量变化趋势，观察渗透率波动；
5. 拓展尝试：基于销量指标设置简单阈值逻辑，模拟指标异常波动预警思路，为预警平台积累实践。

项目产出（本地生成，未纳入仓库，运行代码可生成）：
car_sale_long_format.csv、car_sales_final.csv、统计指标结果表，时序分析图表。
